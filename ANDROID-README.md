# IBRA Soft ERP — Android preparation

This project includes a Capacitor Android wrapper, PWA manifest, app icons, startup splash, offline shell cache, and mobile CSS.

## Build APK using GitHub Actions
1. Upload this project to a GitHub repository.
2. Open **Actions** and select **Build IBRA Soft ERP APK**.
3. Run workflow using **Run workflow**.
4. Download the `IBRA-Soft-ERP-debug-apk` artifact when the workflow succeeds.

The Android folder is generated by the workflow (`npx cap add android`), so no Android Studio is required locally.

## Offline caveat
The service worker caches the application shell. This does not guarantee offline availability for server-dependent features; data currently stored by the app remains governed by its existing storage implementation.
